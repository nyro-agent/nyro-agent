Nyro · AI mining agent · v0.1.0

Mine on every chain. Collect it all in one place.

Nyro watches your rig, node and staking payouts on Solana, Ethereum, Base, Arbitrum, Polygon, Kaspa and Bitcoin. It checks what moving each reward really costs, holds what is not worth the gas, and plans the rest into USDC and on to Robinhood. You sign every step.

How it works

Find it, price the move, then collect

  1. 01

    Find every reward

    scan_earnings reads your payout wallets on all seven chains and shows what came in since the last scan: rig payouts, node rewards, staking and farm tokens.

  2. 02

    Price every move

    plan_harvest asks LI.FI for a live route into USDC for each token and adds up gas, bridge and swap fees. Too small or too expensive? It holds.

  3. 03

    Collect and pay out

    You sign each route in your own wallet. The USDC lands in one wallet, then goes to your Robinhood deposit address with a suggested split, like 70% NVDA and 30% BTC.

Safety model

An agent that plans, and never holds your keys

  • Public addresses only

    Nyro reads balances. Anything that looks like a private key or seed phrase is refused on sight.

  • You sign every step

    Each route comes back as an unsigned transaction. Your wallet signs it. Nyro never sends anything.

  • Fees before moves

    Rewards under your minimum, or routes costing more than your limit (3% by default), are held back until they are worth it.

  • Gas stays behind

    A little of each native coin stays in the wallet, so your rig or node can keep paying for its own transactions.

  • Fresh quotes only

    Plans expire after 10 minutes because prices and gas move. Build a new one before you sign.

  • Robinhood stays yours

    Nyro has no access to your brokerage. The split into stocks is a list of orders you place yourself.

Quick start

See a full harvest in demo mode first

Demo mode loads a sample GPU rig, a DePIN node, staking and a farm, so you can see harvest-or-hold before you add a single address.

  1. Open the web app
    npx -y nyro-agent web
    Dashboard, harvest plan, terminal and settings on http://127.0.0.1:5550. Only your own computer can reach it.
  2. Or add it to your MCP client
    { "mcpServers": { "nyro": { "command": "npx", "args": ["-y", "nyro-agent"] } } }
  3. Ask your agent, or type plan in the terminal
    What did I mine this week, and is it worth moving?

The npm package is not published yet. Until it is, run npm install && npm run build in the source folder, then node dist/index.js web.

~/.nyro/config.json
